# plataformas/

```
plataformas/
├── windows/   a página inicial (React + Tailwind), o cursor dourado e o CSS de tela
└── tipos.ts   as props que a página inicial recebe (abrir Membros, Projetos…)
```

O site tem **uma versão só**, que se ajusta ao tamanho da tela. Até
01/10/2026 esta pasta também tinha `mobile/`, uma versão separada para celular
em React Native; ela foi removida a pedido, junto com a pergunta "Como você
está acessando o Clube hoje?" e o "Modo Windows/Mobile". Uma cópia do código
antigo está em `_backup-antes-de-remover-o-mobile-2026-10-01/`, na pasta de cima
do projeto.

Detalhes da página inicial em `windows/LEIA-ME.md`.
